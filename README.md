## Sobre mim

Sou desenvolvedor Full Stack com foco em **backend robusto** e soluções orientadas a resultado. Atuo na **Pródos Digital** desenvolvendo sistemas sob demanda para empresas privadas e setor público — com ênfase em automação de processos, inteligência artificial aplicada e integrações escaláveis.

Não entrego apenas software. Entrego **redução de custo operacional**, **aumento de produtividade** e **sistemas que escalam com o negócio**.

<br/>

## O que eu construo

```
  Automação de processos      →   Elimino trabalho manual e retrabalho
  Sistemas sob demanda        →   Solução exata para o problema certo
  Inteligência Artificial     →   IA aplicada para decisões mais rápidas
  APIs & Integrações          →   Sistemas que conversam entre si
  Dashboards & BI             →   Dados que viram decisões estratégicas
  Setor Público               →   Conformidade, auditoria e escala
```
